## Задача

Два равенства: нестрогое `==` приводит типы перед сравнением, строгое `===` — нет. Из-за `==` рождается большинство загадочных багов сравнения. Строишь таблицу и понимаешь правило.

```
==  сравнивает, приводя типы:   0 == '0'   → true
=== сравнивает строго:          0 === '0'  → false

null == undefined → true
null === undefined→ false
правило: по умолчанию всегда ===
```

## Что нужно сделать

В `equality.js` сравнить пары и через `==`, и через `===`, вывести оба результата рядом. Пары с подвохом: `0` и `'0'`, `0` и `''`, `null` и `undefined`, `NaN` и `NaN`, `'1'` и `1`, `false` и `0`. Для каждой — прогноз до запуска.

## Критерии приёмки

* Для каждой пары выведены оба результата (`==` и `===`), есть прогноз.
* Отдельно разобран `NaN`: почему `NaN == NaN` и `NaN === NaN` оба `false`.
* В конце вывод: почему по умолчанию используют `===`.
